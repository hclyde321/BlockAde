# 醫學上課錄音考古整合器：開發規格草案

更新：2026-09-25

## 1. 產品目標與已確認需求

使用者上傳一堂課的錄音、題目 PDF、答案解析 PDF。系統先在本機轉錄錄音，整理可同步播放的逐字稿，再分析每題適合出現的講課位置。使用者播放錄音時，可閱讀整份逐字稿並看到目前念到的位置；講完相關內容後，播放器自動暫停並出題。提交答案後立即顯示正解與解析，再繼續播放。

已確認條件：

- 第一版只有一位使用者，在同一台電腦上使用 Web App。
- 輸入以純錄音為主，單堂約 55 分鐘；中文為主，夾雜英文醫學術語。
- Whisper 轉錄必須在本機執行。PDF 解析與題目對應可使用雲端模型。
- 題目和答案解析分屬兩份 PDF，兩者文字均可選取、複製。
- 題型以單選題為主；兩份 PDF 的題號大致一致，少數題目需手動調整配對。
- 播放時反白目前念到的句子或短段落。
- 作答後立即顯示答案與解析，再繼續播放。
- 目前開發電腦為 Apple M1、8 GB 記憶體；正式模型選擇須用真實錄音測速與校驗品質。

## 2. 使用流程

1. 建立課程，輸入課程名稱，分別上傳錄音、題目 PDF、答案解析 PDF。
2. 背景工作依序轉錄、擷取 PDF 文字、辨認題目與答案、建立題目對應位置。畫面顯示進度和錯誤。
3. 進入課程校對頁，檢查逐字稿、題目與答案配對、建議出題時間。可修改逐字稿、配對與出題時間。
4. 開始播放。整份逐字稿保持可見，當前句段反白，點選其他句段可跳轉錄音。
5. 播到出題時間點時暫停，顯示題目與選項，提交答案後顯示正解及解析；使用者按「繼續播放」。
6. 課程結束後查看已作答、答錯、尚未作答及無法可靠對應到講課內容的題目。

## 3. 建議的第一版功能

### 音訊與逐字稿

- 本機轉錄產生帶起訖時間的句段，第一版反白目前念到的句子或短段落；資料結構可保留詞級時間戳，以便日後改善反白精度。
- 支援播放、暫停、倍速、拖曳進度、點逐字稿跳轉、當前句段反白與自動捲動；使用者手動捲動時暫停自動捲動。
- 支援修正醫學術語與錯字。修改文字不應刪除原有時間戳；若整段時間明顯錯誤，可手動調整段落起訖時間。
- 轉錄是上傳後的預處理。播放時的同步反白與出題則依預先產生的時間戳立即反應。

### 題庫處理

- 分別讀取題目及答案解析 PDF，保留原始頁碼、題號及來源文字。
- 先依題號配對；少數題號缺失或不一致的題目列為「待確認」，提供手動配對。
- 第一版優先支援單選題，資料格式保留日後加入其他題型的空間。
- 匯入後提供題目預覽和編修，避免 PDF 換行、表格、圖片或選項順序造成解析錯誤。
- 答案與解析在作答前不顯示；提交後由本機資料庫讀出並展示。

### 題目與講課片段對應

- 預設在本機比對所有題目的題幹與逐字稿，只為有明確且位置唯一的文字證據設定出題時間；其他題目保留未配對，不顯示候選時間。
- OpenAI 分析保留為選用功能，只有使用者明確啟動且已設定 API key 時才送出必要的題目與逐字稿文字。
- 出題時間設在相關概念講完後，而不是老師剛開始講到關鍵詞時。
- 沒有足夠講課證據的題目留在未配對清單，不強行插入播放流程；只有已確認的出題點會自動暫停。
- 使用者可移動、停用或手動新增出題點；若同一位置有多題，依序作答。

### 播放時的出題規則

- 正常向前播放越過出題時間且題目尚未作答時，暫停並顯示題目。
- 已作答的題目不因重播而反覆跳出；使用者仍可從題目清單重新練習。
- 拖曳跳過尚未作答的題目時，清楚標示跳過題目，供稍後補做。
- 作答記錄、播放位置及人工調整在關閉瀏覽器後保留。

## 4. 技術架構

瀏覽器前端負責播放器、逐字稿、校對與作答畫面；本機服務負責檔案處理、轉錄工作、資料儲存及本機文字對位。服務只在本機提供 Web App。錄音和原始 PDF 儲存在本機；若另外啟用雲端分析，傳送必要的題目與逐字稿文字，不需上傳錄音。

建議的模組邊界：

| 模組 | 責任 |
| --- | --- |
| 前端 | 課程管理、播放器、逐字稿同步、題目校對與作答 |
| 本機 API / 工作佇列 | 匯入、處理進度、轉錄任務、儲存與錯誤復原 |
| Whisper 執行器 | 錄音轉文字與時間戳，可替換模型或推論實作 |
| PDF 解析器 | 擷取文字、題號、選項、答案、解析與頁碼 |
| 題目對應器 | 本機高精度文字比對、出題時間建議；選用雲端模型檢核 |
| SQLite | 課程、逐字稿、題目、對應位置、作答與進度 |

這台 M1 / 8 GB 電腦可先測 `whisper.cpp` 的 Metal 推論及量化版 `large-v3`，並和較小模型比較醫學術語正確率、55 分鐘課程處理時間、記憶體使用量。模型名稱不應寫死在資料格式或介面裡。

建議的主要資料關係：`Course` 擁有一份 `AudioAsset`、多個 `TranscriptSegment`、多個 `Question`；`Question` 可有一個 `AnswerExplanation`、零到多個 `QuestionMatch`、多筆 `Attempt`。`QuestionMatch` 保存片段起訖時間、實際出題時間、證據句段、信心狀態及是否經人工確認。

## 5. 開發順序與驗收

| 階段 | 可展示結果 | 驗收重點 |
| --- | --- | --- |
| A. 真實資料試驗 | 用一段課堂錄音與兩份 PDF 驗證轉錄、PDF 結構和題號配對 | 確認 M1 / 8 GB 可用的模型與主要解析難點 |
| B. 聽課核心 | 匯入錄音、顯示完整逐字稿、同步反白、點文字跳轉 | 暫停、拖曳、倍速後反白位置仍正確 |
| C. 題庫核心 | 匯入兩份 PDF、題目與解析配對、人工修正 | 題號、選項、答案、解析和來源頁碼可核對 |
| D. 智慧出題 | 自動建議片段、校對時間、播放時暫停出題 | 題目在相關概念講完後出現；低信心題目不亂跳 |
| E. 練習記錄 | 作答、立即看解析、繼續播放、課後統計 | 重播、跳轉、關閉再開啟後狀態一致 |

在 A 階段先抽樣人工評估轉錄品質與題目對應位置。若真實錄音中醫學術語錯誤多，加入課程專有名詞提示或逐字稿修正流程；若 PDF 結構不一致，優先改善人工校對畫面。

## 6. 待確認項目

實作與驗收需要一份代表性的錄音，以及互相對應的題目、答案解析 PDF。資料可在本機處理；雲端分析文字內容前應讓使用者清楚知道會傳送哪些文字。

## 已確認的持續學習擴充

- 固定四科資料夾：病理學、藥理學、臨床醫學、檢驗醫學；既有資料移入臨床醫學。
- 科目共用多份具名題庫，題目/答案解析 PDF 與錄音分開管理。
- 單堂錄音上傳後自動轉錄、顯示實際進度並比對該科題庫；舊課由使用者選取重新比對。
- 每課獨立作答；真實聽課覆蓋 90% 完成一輪，可重開下一輪，保留所有歷史。
- 錯題最近答對後移出待複習，保留曾錯歷史，可按科目/課程篩選。
- 不加入定時通知或完成提醒。


## 分段轉錄（2026-09-25）

- 每堂課可選每 5 分鐘（預設）或每 10 分鐘獨立辨識，設定持久保存。
- 上傳後使用所選分段自動轉錄；已有錄音提供重新轉錄入口。
- 合併後維持原音訊的絕對時間戳，播放器、字幕及題庫仍使用一條完整時間軸。
- 顯示目前處理段數及整體進度。所有段落完成才替換自動逐字稿，失敗時保留原稿；人工修改內容仍保護。
- 分段可限制辨識重複持續擴散，不能保證完全避免模型辨識錯誤。


## 課程編輯與局部辨識（2026-09-25）

- 可修改課程名稱，保留同一課程 ID、播放位置、學習及作答紀錄。
- 支援輸入開始／結束時間，只重新辨識所選錄音區間並保留完整時間軸。
- 時間界線若穿過既有句段，延伸至完整句段並顯示實際範圍；人工修改內容不被覆蓋。
- 完成後才以交易更新區間逐字稿，重算本機題目配對；失敗時保留原稿。區間辨識不會在服務重啟時自動重播工作。
